Besoin d'aide avec Trinko ? Nous sommes là pour vous aider.

À propos de Trinko

Trinko est une application de jeux de soirée permettant de jouer entre amis, notamment grâce à des parties multijoueur synchronisées entre plusieurs appareils.

Besoin d'aide ?

Si vous rencontrez un problème avec l'application, une partie multijoueur, la connexion entre les appareils ou toute autre fonctionnalité, contactez-nous par e-mail.

E-mail : fmstratégie@gmail.com

Signaler un problème

Lorsque vous nous contactez au sujet d'un problème technique, indiquez si possible :

  • le modèle de votre iPhone ;
  • la version d'iOS utilisée ;
  • la version de Trinko ;
  • une description du problème rencontré ;
  • les étapes permettant de reproduire le problème.
